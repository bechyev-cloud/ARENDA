МурБокс — установка как PWA (приложение на рабочий стол через Chrome)
======================================================================

ВАЖНО: Chrome разрешает установку PWA только со страницы, открытой по
http:// или https:// — открытие файла двойным кликом (file://...) НЕ
подойдёт, кнопка установки не появится. Нужно "раздать" эту папку как
маленький сайт. Вариантов два:

Вариант A. Быстро проверить на своём компьютере (localhost)
-------------------------------------------------------------
1. Установите Python (если ещё не установлен) — на Windows/macOS можно
   скачать с python.org.
2. Откройте терминал/командную строку в этой папке (там, где лежит
   index.html) и выполните:

       python3 -m http.server 8080

   (на Windows иногда команда называется просто "python", без "3")

3. Откройте в Chrome адрес:  http://localhost:8080/
4. Справа в адресной строке появится значок установки (⊕ / экран со
   стрелкой). Нажмите его → «Установить МурБокс». Либо через меню
   Chrome «⋮» → «Установить МурБокс…».
5. Приложение появится на рабочем столе / в списке приложений и будет
   открываться в отдельном окне, без адресной строки браузера.

Оставляйте терминал открытым, пока пользуетесь приложением локально —
если его закрыть, localhost перестанет отвечать.

Вариант B. Разместить в интернете (постоянный адрес, доступ с любого
устройства)
-------------------------------------------------------------
Загрузите содержимое этой папки целиком (index.html, manifest.json,
sw.js, папку icons) на любой бесплатный статический хостинг, например:
- Netlify Drop (netlify.com/drop) — просто перетащить папку;
- GitHub Pages;
- Vercel.

После загрузки откройте выданный сайтом адрес (https://...) в Chrome —
значок установки появится так же, как в варианте A. Этот способ удобнее,
если приложением будете пользоваться постоянно или с разных компьютеров.

Что изменено в файле, чтобы включить PWA
-------------------------------------------------------------
- Добавлены отдельные файлы manifest.json и sw.js (раньше они создавались
  "на лету" через blob:-ссылки прямо в JS — в реальном Chrome такая
  service worker-ссылка не регистрируется, а именно service worker
  и manifest вместе дают браузеру основание показать кнопку установки).
- Добавлены реальные PNG-иконки 192×192, 512×512 и maskable-версия
  (папка icons/) в стиле лого приложения (кот выглядывает из коробки).
- index.html теперь ссылается на эти файлы через <link rel="manifest">
  и navigator.serviceWorker.register('./sw.js').
- Кнопка «Установить приложение» внутри самого МурБокса продолжает
  работать как раньше — она вызывает системный диалог установки Chrome.

Полноэкранный режим на телефоне
-------------------------------------------------------------
- Приложение теперь занимает весь экран телефона по высоте (используется
  100dvh — «настоящая» высота видимой области, без пустых полос при
  скрытии/появлении адресной строки Chrome).
- Свайп вниз внутри приложения (в списках, в настройках, в карточках)
  никогда не запускает системное «обновление страницы» браузера Chrome —
  тянуть вниз можно спокойно, страница не будет перезагружаться.
- Пинч-зум и случайный зум двойным тапом отключены — как в обычном
  установленном приложении, а не в браузере.

Хранение данных — только на этом устройстве
-------------------------------------------------------------
- Все боксы, контакты, платежи, история и настройки теперь автоматически
  сохраняются в localStorage браузера при любом изменении (добавление
  бокса/контакта, платёж, изменение настроек и т.д.) — отдельно ничего
  нажимать не нужно.
- При следующем открытии страницы (или запуске установленного
  приложения) все данные подгружаются автоматически.
- Данные привязаны к конкретному браузеру на конкретном устройстве:
  они не синхронизируются между компьютером и телефоном и пропадут,
  если пользователь очистит данные сайта в браузере. Для переноса на
  другое устройство или подстраховки используйте кнопки в разделе
  «Резервные копии» в настройках (скачать файл / скопировать в буфер /
  восстановить из файла).
- В настройках теперь есть баннер «Данные хранятся на этом устройстве»,
  который показывает, сколько боксов и контактов сохранено и сколько
  места это занимает.

Настройки переоформлены
-------------------------------------------------------------
Экран настроек разбит на аккуратные карточки-разделы (Компания, Тарифы
и отображение, WhatsApp и автоматизация, Напоминания, Резервные копии) —
каждая со своей иконкой и коротким пояснением, вместо одного длинного
списка полей подряд. Каждый раздел сворачивается и разворачивается по
тапу, как папка.

PDF-отчёт клиенту — исправлена кириллица
-------------------------------------------------------------
Раньше PDF-отчёт клиенту открывался с «кракозябрами» вместо русских
букв — у встроенных шрифтов jsPDF (Helvetica и т.п.) в принципе нет
кириллических символов, они физически не могут их отобразить.
Теперь в приложение встроен шрифт (урезанная версия DejaVu Sans —
только латиница, кириллица и нужные символы вроде ₽, чтобы не раздувать
файл), и PDF-отчёт использует именно его. Работает полностью офлайн,
ничего скачивать не нужно.

PDF-отчёт клиенту — аккуратная таблица вместо простого текста
-------------------------------------------------------------
Документ полностью переоформлен:
- Шапка — золотая плашка с названием компании и датой формирования.
- Карточка клиента — ФИО, телефон, адрес, боксы в аккуратном блоке.
- Баланс — «Оплачено / Долг за аренду / Долг за свет» построчно,
  «Итого долг» выделено отдельной золотой плашкой.
- История платежей — настоящая таблица с колонками «Дата / Тип / Бокс /
  Сумма», с шапкой таблицы и чередующейся заливкой строк (зебра) для
  удобного чтения. Если платежей ещё не было — аккуратный пустой блок
  вместо голого текста.
- Если платежей много и они не помещаются на одну страницу — таблица
  сама переносится на следующую страницу с повтором заголовка колонок.
- Внизу каждой страницы — название компании, дата и номер страницы.
